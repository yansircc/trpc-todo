# tRPC v11 优化总结

## 已完成的优化

1. **Client 优化**
   - 使用 `httpBatchStreamLink` 替换 `httpBatchLink`，支持流式响应
   - 提取 `QueryClient` 逻辑到独立的 `query-client.ts` 文件
   - 合并 `client.tsx` 和 `index.ts`，减少冗余代码和导入

2. **路由器增强**
   - 使用 v11 简写语法组织路由
   - 添加 `FormData` 支持，用于文件上传
   - 添加流式响应示例，使用生成器和 `httpBatchStreamLink`
   - 增强错误处理和数据验证

3. **服务器组件支持**
   - 使用 `createHydrationHelpers` 优化服务器组件和客户端状态管理
   - 通过 `getQueryClient` 在服务器端预取数据

## 下一步可能的改进

1. **路由结构优化**
   - 当前的路由器结构使用了大量的嵌套，可以根据业务逻辑进一步优化
   - 可以考虑使用更多的子路由器来组织相关的功能

2. **FormData 和文件上传 UI**
   - 添加文件上传组件，展示 FormData 支持
   - 创建文件预览和进度显示功能

3. **统计和仪表板功能**
   - 使用 `stats` 流式响应创建实时统计仪表板
   - 可以展示完成的任务百分比、剩余任务等

4. **订阅和实时更新**
   - 添加 SSE 订阅功能，在其他用户更新 Todo 时接收实时通知
   - 可以用于协作场景

5. **性能优化**
   - 使用 v11 的批处理和预取策略
   - 添加缓存控制和优化

## 注意事项

1. **类型兼容性**
   - 在修改路由结构时，确保客户端代码也相应更新
   - 使用 TypeScript 的类型推断确保类型安全

2. **测试覆盖**
   - 为新功能编写测试
   - 确保路由、验证和错误处理按预期工作

3. **迁移策略**
   - 从 v10 迁移到 v11 时，遵循渐进式策略
   - 先更新核心依赖，然后逐步采用新特性
